# Contratos iniciales
Los JSON Schema cubren estructura general. `blocks[].props` es deliberadamente extensible en este kit; Codex debe implementar validadores estrictos por tipo de bloque, URLs, IANA timezone, rangos de fechas y unicidad de IDs. Estos esquemas solos no son una barrera de seguridad de producción.
El template es configuración; la invitación almacena documento y referencias de medios, nunca JSX ni funciones.
