# Templates Pixvo propuestos
Los 27 presets son configuraciones iniciales, no componentes React terminados. Cada uno enlaza su referencia observada y usa un SVG nuevo. Sus nombres Pixvo son propuestas editoriales.
Las tipografías de invitación son sugerencias derivadas de las previews; sus archivos/licencias deben incorporarse en implementación. El esquema de colores no certifica contraste en todas las combinaciones: validar y ajustar antes de publicar.
Los fondos SVG son recursos vectoriales de partida, no equivalentes fotográficos. El cliente puede reemplazarlos. Cinco familias deben implementarse con composiciones diferentes según layoutNotes.
